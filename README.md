# Course Overview

## Topics

- Understanding EventEmitter
- Understanding Buffers
- Understanding File System
- Understanding Streams

## Course Outline

- **Understanding EventEmitter**

  - Learn the basics of the EventEmitter class in Node.js.
  - Understand how to create custom events and handle them efficiently.

- **Understanding Buffers**

  - Deep dive into buffers and binary data manipulation.
  - Essential knowledge for working with raw binary data in Node.js.

- **Understanding File System**

  - Comprehensive overview of the Node.js `fs` module.
  - Master file operations: reading, writing, file uploads, and more.
  - Practical examples to solidify understanding of file handling.

- **Understanding Streams**
  - In-depth exploration of Streams for handling large data efficiently.
  - Implementation of custom readable and writable streams.
  - Build mini-projects to practice stream manipulation:
    - Encryption-decryption app for terabytes of data.
  - Foundation for creating high-performance network applications.
